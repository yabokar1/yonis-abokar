# Yonis Abokar — portfolio

Private site for job applications. It describes three projects. It does not contain the Proactive Drivers source code. That client repository stays private.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually http://localhost:5173.

## Build

```bash
npm run build
npm run preview
```

The static files land in `dist/`. Deploy that folder when you want a public URL. The GitHub repository can stay private.

## What is on the site

- Proactive Drivers — freelance booking platform. Case study only.
- SafeGPT — anonymization API from the DITA Research Lab, with links to the public repos.
- LearnedWMP — SIGMOD Companion 2025 demo. The résumé line that says ICDE should say SIGMOD.
